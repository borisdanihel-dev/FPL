- `tools/xp_v2_live.py`:
  - `core()` is S6b's `Replay.xp_v2` term by term. Fed S6b's own inputs it
    returns S6b's numbers exactly: real 2025/26 GW5 (342 players), GW21
    (319), GW38 (334), max |difference| 0; the toy test asserts equality
    of every term.
  - `forecast()` builds the same inputs from one 2026/27 export: the
    training slice truncated to the export's gameweek; S11's shares from
    the export's rows (one unit per player-gameweek; no double gameweek and
    no PL-to-PL move since the first dated export); S11's `Prior` on
    2025/26, keyed by `code` (481 players reach their 2025/26 name that
    way), else the 2026/27 full name; S5's `fixture_lambdas` from the
    newest Odds API snapshot before the deadline, else the fallback; the
    status gate `a` with S6b's 45-minute gate; P(sub) × chance (S6's live
    rule).
  - `live()` refuses an export generated at or after the deadline;
    `retro(g)` takes gameweek g's newest pre-deadline export and S5's
    2026/27 football-data book.
- `tools/gw_pass.py` section 5 "OWN v XP_V2 AS TESTED": the XI, bench
  order and captain by each, side by side; the header names xp_v2 as tested
  the default from GW8 (ruling point 1); with a missing input it prints
  `missing input` and `own picks GW8`. The keeper line adds each keeper's
  xp_v2. The S6 forecast on the recorded xg rows left the bundle.
- `tools/xp_v2_replay.py --s6c`: the GW5–7 print has the live column, with
  captains by name.
